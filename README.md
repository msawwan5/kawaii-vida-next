# Kawaii Vida Next.js

Next.js recreation of the original single-file Kawaii Vida website.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Structure

- `app/page.tsx` contains the site sections.
- `app/globals.css` contains the visual system and responsive styles.
- `components/SiteEffects.tsx` contains cursor, petal, reveal, and canvas animations.
